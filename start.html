01 / 检查项目

我的项目，还差什么？

适合课程设计、大创或个人项目。先建一张能检查的目标清单。

  1. 写项目名称与具体目标
  2. 按目标补充检查材料
  3. 保存每轮检查与下一步待办
开始项目检查 ↗

到达后点击“开始新项目检查”。暂时没材料，也可以先建清单。

02 / 比较 AI 记录

AI 做得怎样，投入多少？

把已经完成的 AI 任务填进表单，逐项记录依据和实际用量。

  1. 确定同一任务的目标
  2. 填写执行记录与验收依据
  3. 下载数据，在工作台比较
填写我的任务记录 ↗

不需要写 JSON。没有用量就留空；这一步不会启动 AI。

03 / 继续已有文件

手里有文件，该在哪打开？

任务数据、检查备份和评估报告用途不同。先辨认，再去对应入口。

  1. 选择已保存的 JSON 文件
  2. 查看类型和使用步骤
  3. 到目标页面重新选择文件
识别文件用途 ↓

只在浏览器内读取。不会修改、上传或自动导入你的文件。

继续上次的工作

这份 JSON 应该放在哪里？

最多 16MiB，仅识别格式与入口。目标页面仍会检查完整内容。

本地文件指引

选择文件后显示用途；不会自动替换任何工作台的数据。

    先花五分钟，熟悉一次流程

    还没有自己的记录？

    用内置虚构任务练习。它们展示失败、证据缺失和不同用量，不代表真实模型表现。

    打开工作台体验 ↗

    新打开的工作台默认载入示例。不会重置其他已打开的页面。

    1. 看同一任务的几条记录先看必需目标和依据，再看 token；低用量也可能没有完成任务。
    2. 查看证据，尝试调整预算观察候选记录为何变化。只重新评估现有记录，不调用模型。
    3. 保存数据，再生成报告点击“保存当前数据”，到“报告对照 → 从任务数据生成”重新选择下载的文件。
    4. 改一个条件，再做一次对照保留第一份报告，修改预算生成第二份；对照会提示条件变化，不能据此声称 AI 进步了。

    离开前，保存对的那份文件。

    任务工作台与手动录入内容留在当前页面内存。录入未完成时可保存草稿继续填写；完成后下载任务数据。离页提醒不等于已经保存。

    项目体检新建和导入记录可保存在当前浏览器。重要更新后导出检查数据或整批备份，换浏览器前尤其需要。

    报告对照下载原始评估报告和对照结果。对照结果仅供阅读，重新比较仍需要两份原始报告。
