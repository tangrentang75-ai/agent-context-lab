# 任务罗盘 · Agent Context Lab

**以用户目标为起点，复核 AI 任务的验收证据、执行过程与资源投入。**

大学生创新创业训练计划候选项目。当前 v0.3 提供网页评估、本机 Codex 执行连接与上下文对照预实验。内置演示数据仍为人工构造；真实记录单独显示。尚无通用性能提升结论。

## 扩展后的课题定位

候选题目：**《面向用户目标的智能体任务评估与资源分配方法研究及平台开发》**。

AI 能搜索、编程、整理资料和处理数据；用户关心的是这些工作是否实现了自己的目标。平台将目标约定、执行记录、验收证据和资源成本关联起来，探索如何在保证目标完成质量的前提下分配资源。

软件成果是一套独立网页平台，接入不同 AI 工具的适配器可以是插件。代码修复仍是首个真实研究场景，资料研究和数据处理用于展示产品扩展能力，不意味着已经完成跨场景验证。

## 第一版已实现

- 三种场景、七条人工构造记录；任务搜索与场景筛选。
- 设置目标权重与必需项，查看基于验收状态计算的目标得分。
- 查看探索、执行、验证时间线，以及逐项目标的证据。
- 人工修正验收结论；判定通过或未通过时必须提供依据。
- 按同一任务、同一声明条件组比较记录，应用 token 预算。
- 排除验收失败、证据不完整、成本未知或超预算的记录；标记合格记录中 token 最少的结果。
- 下载 JSON 示例、导入自定义记录、导出当前任务评估报告。
- 手机与桌面布局；浏览器本地处理，无第三方页面脚本。

新增：调用本机已登录的 Codex，完成固定报名修复题；用 8 条独立测试验收，记录真实 token、耗时与最终修复选择，保存最近结果。

v0.3 新增：三种上下文各重复 3 次，固定模型请求名与推理强度，运行前保存协议，保留失败与未知成本；网页查看组内汇总、逐次证据和完整数据集导出。已完成 9 次真实调用，全部通过验收，详见 [预实验报告](context-study-report.md)。这只是一道受限题，不能推广成节省算力结论。

**尚未实现：**任意仓库修复、后台数据库、账户与协作、在线资源分配策略、通用隔离执行环境。

## 运行

直接用浏览器打开 `index.html` 即可使用。也可以在 Node.js 20 或以上版本下运行：

```sh
npm start
```

然后打开 http://127.0.0.1:4173 。无需安装 npm 依赖。开发服务器只监听本机，使用固定文件白名单。

没有 npm 时也可直接运行 `node server.cjs`。真实运行需本机安装 Codex CLI 并完成 `codex login`；服务复用 CLI 登录，不读取或复制凭据，不需要把密钥填进页面。Windows 会检测桌面应用附带的 Codex；也可设置环境变量 `CODEX_BIN` 为可执行文件路径。仅直接打开 HTML 时，仍可使用离线评估，无法调用执行器。

点击“运行真实测试”，等待完成后查看验收证据；点击“查看最近结果”恢复本机上次记录。每次运行会使用 Codex 额度。也可运行 `node codex-bridge.cjs` 获取同一实验的 JSON 输出。

执行器用只读模式、临时目录、结构化答案和 3 分钟超时。仅允许预定义的修复选择进入可信测试函数，不执行模型生成的任意代码。模型默认值未固定，因此每次调用独立分组，不能用于策略优劣比较。详细边界见 [真实接入说明](live-experiment.md)。

## 验证

```sh
npm test
```

或 `node --test evaluation.test.cjs bridge.test.cjs context-study.test.cjs`。测试本身不会调用模型。

上下文对照运行：`node context-study.cjs` 或 `npm run study`。最多 9 次；连续两次执行失败或已报告累计用量达到 180,000 tokens 后停止后续调用，不自动重试。停止阈值是调用间检查，非硬性计费上限。它不会修改原来的单次测试结果；完成后在网页点击“查看上下文对照”。

测试覆盖质量门槛、缺失证据、缺失成本、预算限制、条件组隔离、无效导入和并列结果。浏览器还应检查导入、预算交互、人工复核与报告导出。

## 使用和数据边界

从任务卡片进入策略比较，调整目标和预算，点击“应用预算”；进入记录详情查看或修正验收证据；导出评估报告保存当前任务和复核结果。更改条件仅重评已有记录，不会重新运行 AI。

页面复核修改仅保存在内存中，刷新会丢失；原始真实结果保存在本机 `runs/`，可用“查看最近结果”恢复。该目录已忽略，不上传仓库。平台不会自行证明导入记录真实，也不会执行日志中的代码或指令。导入说明见 [数据格式](data-format.md)。

成本未知不等于零成本；token 不等同于硬件算力；重复操作不自动等于浪费；单次优胜不等于策略普遍更好。
