# Agent Context Lab

**面向 AI 编程助手的代码探索分析与评估平台。**

这是一个大学生创新创业训练计划的候选项目，当前处于选题验证与产品规划阶段。项目名称和研究范围可以随调研调整。

## 要解决的问题

AI 在修改代码前通常需要搜索项目、阅读文件和确认依赖。人觉得多余的步骤，可能实际帮助了修复；看起来认真、充分的探索，也可能没有改善结果。

本项目希望通过可观察的操作记录和对照实验，研究：**什么时候继续获取代码信息有帮助，什么时候已经可以开始修改？**

## 软件成果形态

计划交付一个可操作的网页工具，支持开发者和研究者：

1. 导入 AI 编程助手的运行记录，按时间查看搜索、阅读、修改、测试和返工过程。
2. 查看阅读文件、工具调用、token 用量和耗时；缺失的数据明确显示为未知。
3. 对比同一任务采用不同探索策略后的修复结果与总成本。
4. 在后续实验支持的基础上，给出继续探索或开始修改的建议，并展示依据。
5. 导出实验报告，支持项目演示和研究复现。

第一版优先实现日志导入、过程展示和策略对比。自动执行代码与在线停止策略属于后续阶段。

## 候选研究题目

《面向 AI 编程助手的代码探索停止策略研究与可视化平台开发》

这是工作题目，尚未证明独立创新性。更少的阅读、更少的 token 或更短的执行时间，都不能单独证明系统更有效；需要同时检查任务完成质量与后续返工。

## 相关研究线索

- [SWE-Explore: Benchmarking How Coding Agents Explore Repositories](https://arxiv.org/abs/2606.07297)：代码探索的评估。
- [Evaluating AGENTS.md: Are Repository-Level Context Files Helpful for Coding Agents?](https://arxiv.org/abs/2602.11988)：项目背景文件的效果与成本。
- [Agent Retrieval Bench](https://arxiv.org/abs/2607.24882)：面向编程工作流的相关文件检索评估。

这些工作与本项目直接相关，需要进一步阅读全文、核查版本与可复现条件；不能把代码探索效率或上下文检索本身视为尚无人研究的创新点。

## 数据与凭据

仅导入有权处理的代码和日志。日志可能包含源码、路径、提示词与凭据，分享前应检查并脱敏。不要提交 API 密钥、访问令牌或真实私有项目的运行记录。
