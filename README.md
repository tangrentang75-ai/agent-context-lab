# 任务罗盘 · Agent Context Lab

**以用户目标为起点，复核 AI 任务的验收证据、执行过程与资源投入。**

大学生创新创业训练计划候选项目。当前提供可在浏览器运行的 v0.1 原型，内置数据均为人工构造示例，尚无真实模型实验或性能提升结论。

## 扩展后的课题定位

候选题目：**《面向用户目标的智能体任务评估与资源分配方法研究及平台开发》**。

AI 能搜索、编程、整理资料和处理数据；用户关心的是这些工作是否实现了自己的目标。平台将目标约定、执行记录、验收证据和资源成本关联起来，探索如何在保证目标完成质量的前提下分配资源。

软件成果是一套独立网页平台，接入不同 AI 工具的适配器可以是插件。代码修复仍是首个真实研究场景，资料研究和数据处理用于展示产品扩展能力，不意味着已经完成跨场景验证。

## 第一版已实现

- 三种场景、七条人工构造记录；任务搜索与场景筛选。
- 设置目标权重与必需项，查看基于验收状态计算的目标得分。
- 查看探索、执行、验证时间线，以及逐项目标的证据。
- 人工修正验收结论；判定通过或未通过时必须提供依据。
- 按同一任务、同一声明条件组比较记录，应用 token 预算。
- 排除验收失败、证据不完整、成本未知或超预算的记录；标记合格记录中 token 最少的结果。
- 下载 JSON 示例、导入自定义记录、导出当前任务评估报告。
- 手机与桌面布局；浏览器本地处理，无第三方页面脚本。

**尚未实现：**真实模型接入、自动验收、后台数据库、账户与协作、在线任务执行和资源分配、隔离执行环境。

## 运行

直接用浏览器打开 `index.html` 即可使用。也可以在 Node.js 20 或以上版本下运行：

```sh
npm start
```

然后打开 http://127.0.0.1:4173 。无需安装 npm 依赖。开发服务器只监听本机，使用固定文件白名单。

## 验证

```sh
npm test
```

测试覆盖质量门槛、缺失证据、缺失成本、预算限制、条件组隔离、无效导入和并列结果。浏览器还应检查导入、预算交互、人工复核与报告导出。

## 使用和数据边界

从任务卡片进入策略比较，调整目标和预算，点击“应用预算”；进入记录详情查看或修正验收证据；导出评估报告保存当前任务和复核结果。更改条件仅重评已有记录，不会重新运行 AI。

本版数据仅保存在页面内存中；刷新、关闭页面或恢复示例会丢失会话修改。平台不会自行证明导入记录真实，也不会执行日志中的代码或指令。导入说明见 [数据格式](data-format.md)。

成本未知不等于零成本；token 不等同于硬件算力；重复操作不自动等于浪费；单次优胜不等于策略普遍更好。
